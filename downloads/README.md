# Windows test build

Download **Sims3-Windows-test.zip** using the file page's **Download raw file**
button. Extract the entire ZIP and double-click **Sims3.exe**. Keep the adjacent
folders and DLLs together. A separate emulator or Python install is not needed.

The ZIP is about 140 MiB and is stored using Git LFS. Download the ZIP file
itself; GitHub's automatic repository source ZIP may contain only an LFS pointer.

This is experimental. The original title/agreement graphics, mouse input, and
normal window close were validated under Wine 10. Physical Windows 11 and full
gameplay remain unverified; audio is not implemented. EA's original agreement
remains for you to review and accept.

Saves and logs: `%LOCALAPPDATA%\Sims3Mobile`.
